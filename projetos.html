ECO Metrópole - 1° Bimestre

No primeiro bimestre, desenvolvi um jogo educativo inspirado na ODS 11 (Cidades e Comunidades Sustentáveis). O objetivo do jogo era conscientizar sobre a importância do descarte correto de resíduos por meio de uma personagem que precisava recolher os lixos espalhados pela cidade e colocá-los nas lixeiras correspondentes, enquanto desviava de obstáculos e pulava desafios ao longo do percurso. O projeto foi desenvolvido na plataforma Construct 3, responsável pela programação e funcionamento do jogo, enquanto todo o design dos cenários, personagens e elementos visuais foi criado no Canva. Essa atividade permitiu desenvolver habilidades em programação, design e pensamento criativo, além de reforçar a importância da sustentabilidade.

Tech Fast - 2° Bimestre

No segundo bimestre, participei do desenvolvimento de um site para a loja de roupas Gabisa, com o objetivo de oferecer uma solução para os desafios administrativos enfrentados pela empresa. Para compreender melhor as necessidades da loja, nossa equipe realizou uma visita ao estabelecimento, onde conversamos diretamente com os responsáveis e fizemos perguntas sobre as principais dificuldades do dia a dia. Com base nessas informações, desenvolvemos um sistema que incluía funcionalidades como controle de estoque de roupas, gerenciamento de funcionários, registro de compras e controle de vendas. O projeto foi apresentado pela nossa empresa fictícia, TechFest – Tecnologia que Simplifica, criada para representar uma empresa de tecnologia voltada ao desenvolvimento de soluções práticas e eficientes para negócios. Essa atividade contribuiu para o desenvolvimento de habilidades em análise de problemas, criação de sistemas e trabalho em equipe.

Reserva de Laboratórios - 3° Bimestre

No terceiro bimestre, desenvolvi, em equipe, um sistema de reserva de laboratórios para uma escola. O projeto foi construído utilizando Python no Visual Studio Code e integrado a um banco de dados, no qual cadastramos todas as informações necessárias, como professores, laboratórios, horários disponíveis e reservas realizadas. Após a estruturação do banco de dados, realizamos a integração com o sistema em Python, desenvolvendo a interface e as funcionalidades do site para permitir o gerenciamento das reservas de forma prática e organizada. Esse projeto ampliou meus conhecimentos em banco de dados, programação, integração entre sistemas e desenvolvimento de aplicações voltadas para resolver necessidades reais.
